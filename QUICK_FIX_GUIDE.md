# Quick Start Guide - Fixed Version

## 🚀 Local Development (Quick Start)

### First Time Setup
```bash
# 1. Navigate to project directory
cd c:\Users\DEEPANSHU\Documents\simple-version\copo_management_system

# 2. Activate virtual environment
venv\Scripts\activate

# 3. Install dependencies (if not already installed)
pip install -r requirements.txt

# 4. Run migrations (creates SQLite database)
python manage.py migrate

# 5. Create superuser (optional, for admin access)
python manage.py createsuperuser

# 6. Start development server
python manage.py runserver
```

### Daily Development
```bash
# 1. Activate virtual environment
venv\Scripts\activate

# 2. Start server (that's it!)
python manage.py runserver
```

Access at: http://127.0.0.1:8000/

## 🌐 Production Deployment (Render)

### One-Time Setup
1. Connect GitHub repository to Render
2. Set environment variables in Render Dashboard:
   - `SECRET_KEY` - Auto-generated by render.yaml
   - `DEBUG` - Set to `False`
   - `ALLOWED_HOSTS` - Set to `.onrender.com`
   - `DATABASE_URL` - Auto-set by PostgreSQL database

### Deploy
```bash
# Commit and push changes
git add .
git commit -m "Your commit message"
git push origin main
```
Render will automatically build and deploy.

## 🆘 Troubleshooting

### Server won't start
```bash
# 1. Check if virtual environment is activated
# You should see (venv) in terminal prompt

# 2. Install dependencies
pip install -r requirements.txt

# 3. Run migrations
python manage.py migrate
```

### Missing packages error
```bash
pip install -r requirements.txt
```

### Database errors
```bash
# Reset database (WARNING: Deletes all data!)
del db.sqlite3
python manage.py migrate
python manage.py createsuperuser
```

### Static files not loading
```bash
python manage.py collectstatic --noinput
```

### Port already in use
```bash
# Use different port
python manage.py runserver 8001
```
